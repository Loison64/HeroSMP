# 🦸 HeroSMP

Serveur Minecraft Java 1.12.2 sur le thème des super-héros.

## Base
- Minecraft Java 1.12.2
- Forge 1.12.2
- Lucraft: Core
- Heroes Expansion
- Iron Man
- Speedster Heroes

## Structure
- `mods/` — mods du serveur
- `config/` — configurations
- `scripts/` — scripts de démarrage
- `docs/` — documentation

> Les mods exacts seront complétés après identification de la capture d'écran du modpack.
