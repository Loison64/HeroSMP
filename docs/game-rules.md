# Règles HeroSMP

1. Respect des autres joueurs.
2. Pas de triche, X-Ray ou client donnant un avantage injuste.
3. Pas de grief volontaire.
4. Pas de vol hors des règles prévues par le serveur.
5. Les pouvoirs et équipements des super-héros doivent respecter les règles du serveur.
6. Les décisions d'administration doivent être communiquées clairement.
7. Les bugs exploitables doivent être signalés aux administrateurs.
8. Les mods et versions utilisés doivent correspondre au pack officiel HeroSMP.

## PvP
Le PvP est activé par défaut. Les règles spécifiques entre joueurs pourront être ajoutées avant l'ouverture du serveur.
