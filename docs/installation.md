# Installation HeroSMP

## Version
Minecraft Java 1.12.2 + Forge 1.12.2

## Installation
1. Installer Forge 1.12.2.
2. Placer les mods HeroSMP dans `mods/`.
3. Placer les configurations fournies dans `config/`.
4. Lancer le serveur avec `scripts/start.bat`.
5. Accepter l'EULA dans `eula.txt`.

La liste finale des mods sera complétée après identification de la capture du modpack.
